What it checks

Every door intruders usually use

This PC

Open ports and which program listens on them, firewall, antivirus, SMBv1, Remote Desktop, UAC, updates, BitLocker, Secure Boot and TPM, user accounts and startup items.

Hardening

LSA protection and WDigest, NTLM, memory integrity and Credential Guard, Defender ASR rules and cloud protection, SmartScreen, LLMNR and NetBIOS, SMB signing, PowerShell 2.0, USB autorun and Office macros.

Physical access

Whether someone can bypass the password through accessibility tools, boot from a USB stick with an unencrypted disk, and how BitLocker PIN, auto-lock and failed sign-ins are set up.

Your network

Which devices are on your home or office network and which services they expose. Only the private ranges of your own adapters, only plain connections - no attacks, no password guessing.

Network and traffic

How you are connected, which programs talk to which addresses, who connects to you, who is on the network. Open Wi-Fi, IPv6 bypassing the VPN, shared folders on public networks, remote access tools.

Ready for trouble

Backups and restore points, outdated software, open Wi-Fi networks your PC joins on its own, and which apps used the camera and microphone.

Browsers new

Chrome, Edge, Yandex Browser, Brave, Vivaldi, Opera and Firefox, all profiles. Extensions installed outside the store or forced by policy, extensions with access to every site. Foreign policies that set the home page, search or proxy.

Downloaded files new

The last 30 days of Downloads: double extensions, reversed names, scripts and shortcuts, documents with macros. Each file has “Scan with antivirus”, “Show in folder” and “Move to Recycle Bin” buttons.

Router new

Whether UPnP is on and which ports programs have opened to the internet through your router. Remote Desktop or shared folders exposed outside - critical. Instructions for turning UPnP off.

Protection index

The stone clears as protection grows

After a check Adamant gives an index from 0 to 100 and a stone clarity grade. A single critical finding keeps the index at 49 or below: one open door matters more than ten closed ones. The history is kept day by day.

  • Dark
  • Cloudy
  • With inclusions
  • Clear
  • Flawless
Findings by severity

Critical, Important, Advice, Not visible, OK. Each one explains in plain words what it means and what to do. The report can be printed or saved as PDF or HTML.

On watch

Not just a check, but a guard

The Guard

Remembers how your system is set up: services, tasks, startup items, certificates, hosts, DNS, proxy, antivirus exclusions, administrators. Each check shows what has changed. It looks for signs of intrusion in the Windows logs of the last 14 days. The “When it was used” chart is a day × hour grid: you can see when the PC was on and when someone typed a wrong password.

Security checklist

31 tips in plain words: sign-in and accounts, Windows and apps, data and disk, network and router, Wi-Fi, Bluetooth and USB drives, habits. Why you need a firewall and why guests and smart-home devices belong on a separate network. What the check can see is ticked automatically; where a fix exists, there is a “Do it automatically” button.

Program updates new

“Find updates” asks the winget catalogue, “Update” installs new versions - of one program or all of them, one by one, with a summary. Only when you press the button.

Ports in plain words new

Every open port gets a clear name, what it does and a verdict: “Better close”, “Can close”, “Normal”, “Part of Windows”. Click a port to see who opened it and what will stop working. “Close…” adds a firewall rule, the program is not removed, and “Open again” is one click. In the full version “Close what is not needed” closes everything unneeded at once.

Real-time Guard full version

While Adamant is running (even minimized to the tray), it checks startup items, services, tasks, administrators, Defender, hosts and proxy every minute. An important change raises an alarm in the window and the tray. Regular program updates and its own fixes don't.

Alarm full version

A red button cuts the PC off the network (cable and Wi-Fi) and records the programs started in the last 30 minutes. “Restore network” turns everything back on.

Telegram notifications full version

Alarms reach you in Telegram through your own bot. Off by default. Only the short alarm text is sent, and the bot key stays on this PC.

Bluetooth full version

Only listens, never connects: who is nearby, item trackers, attack devices such as Flipper Zero and BadUSB, fake “connect your headphones” pop-up spam, all paired devices.

Sign-in protection full version

A step-by-step wizard that closes ways to get around the Windows sign-in: recovery key, a startup PIN through Windows' own BitLocker wizard, BIOS/UEFI password and boot order.

Drills and decoys full version

Drills prove that protection actually works: the EICAR test file, an AMSI test script, a write attempt into Documents, a “neighbour on the network” view. Decoys are hidden files: if ransomware touches them, you get an alarm. All harmless and only run when you choose.

While you were away full version

While the PC is locked or asleep, Adamant records failed passwords, other sign-ins, started programs, USB drives and file changes. When you return - a timeline and an “It was me” button. Optionally, a photo of whoever typed a wrong password. Everything stays on your PC.

Honestly

What Adamant does and doesn't do

Does

Checks only read settings and logs. A fix is applied after you press Apply and confirm the Windows administrator prompt; previous values are saved and every fix can be undone. BIOS passwords, BitLocker and firmware are never changed by the program - you get step-by-step instructions instead. Program updates and moving files to the Recycle Bin happen only when you press the button.

Doesn't

Doesn't send anything to the internet on its own: no analytics, no self-updates - the program itself downloads and installs nothing. Three exceptions, only if you choose them: finding and installing program updates through winget when you press the button, “Check for updates” in About (one request to GitHub for the latest version number, with nothing about you or your PC), and Telegram notifications if you turned them on. Doesn't scan other people's networks or external addresses. Doesn't read Wi-Fi or auto sign-in passwords. Doesn't replace your antivirus - it checks that it is on and configured.

The archive holds the same package: extract it and run “Установить Адамант.cmd” (Install Adamant).

Your browser or Windows shows a warning? That is expected. Adamant is not yet signed with a paid developer certificate, and Windows and browsers warn about any new program that few people have downloaded. The warning itself does not mean the file contains a virus.

  1. The browser blocks the download. Open the downloads list (the arrow at the top right), click the file or the “…” next to it and choose “Keep”. In Edge, then click “Show more” → “Keep anyway”.
  2. A blue window “Windows protected your PC”. Click “More info”, then “Run anyway”. The installer does not ask for administrator rights.

Do this only with the file from this page or from GitHub datadiver-ru. If someone sent you Adamant in a chat or it is on another site, do not run it.

For advanced users: to check the file was not tampered with, run Get-FileHash .\Adamant-Setup-1.2.6.exe in PowerShell. The result must match the SHA-256 above.

Already have Adamant? Install the new version over it: settings, reports and the full version key are kept. If it offers to update the administrator helper, that takes one Windows prompt. Starting with 1.2.3, you can find new versions with the “Check for updates” button in Settings → About.
