Как огранялся Одем

История по версиям: что вошло в каждую. Новые записи появляются здесь с каждым выпуском.

  1. Версия 1.2 · текущая

    Крипта, синхронизация и открытое ядро

    • Криптокошельки: счета в BTC, ETH, USDT и других монетах с точностью валюты, курсы вручную, переоценка.
    • Отчёт «Выплаты сотрудникам по каналам»: касса, банк, переводы, криптокошельки.
    • Синхронизация между компьютерами через общую папку (OneDrive, Яндекс Диск, сетевая папка): туда уходит только шифр, пишет один компьютер, конфликт не перезапишет данные.
    • Открытое ядро безопасности: шифрование, подписанный журнал и схема Шамира - отдельным пакетом с лицензией MIT.
    • Установщик на один компьютер без прав администратора и комплект для переноса одним архивом.
    • Бета: дистрибутив - по запросу в Telegram @data_diver_ru.
  2. Версия 1.1

    Проверяемый журнал

    Безопасность

    • Журнал аудита подписывается ключом установки (Ed25519). Аудитор проверяет выгрузку журнала без пароля.
    • Журнал доступа: кто, когда, с какого адреса и что открывал.
    • «Четыре глаза» для удаления документов к проводкам, шаблонов и регулярных операций.
    • Ограничения сверх роли: можно запретить пользователю отчёты, выгрузки, просмотр документов, сторно.
    • Ключ восстановления делится на части по схеме Шамира (например, любые 2 из 3).
    • Перед первым запуском новой версии программа сама делает резервную копию.

    Учёт и отчёты

    • Печать и PDF для отчётов и журнала.
    • КУДиР по форме приказа Минфина № 135н, декларация по УСН в XML (формат 5.09).
    • Выгрузки для 1С: банковская выписка «Клиент-банк» и проводки.
    • Загрузка контрагентов, плана счетов и остатков из Excel и CSV.

    Работа и упаковка

    • Сервер для офиса в один щелчок: HTTPS и обязательная 2FA настраиваются сами.
    • Английский интерфейс, запуск ярлыком.
    • Бесплатная версия с полной защитой: 1 компания и до 3 пользователей.
  3. Версия 1.0

    Первый камень

    • Двойная запись, несколько компаний и валют, роли пользователей.
    • Шифрование всех данных на диске, 2FA, журнал аудита, резервные копии.
    • Налоги РФ, Казахстана, Беларуси, США и ЕС; документы к проводкам.
    • Работа в локальной сети.
