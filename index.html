Принципы

Три правила для каждого камня

Zero-knowledge
«Мы не можем прочитать ваши данные.»

Данные шифруются на вашем компьютере ключом из ваших паролей. Наружу уходит только шифр.

Open-core
«Ядро будет открыто. Приватность бесплатна.»

Исходный код ядра откроем для проверки. Защита не продаётся и не урезается: бесплатная версия защищена так же, как полная.

Offline-first
«Работает без интернета.»

Без облака, аналитики и обновлений из сети. Всё работает на вашем компьютере или в офисной сети.

Рождён из огня, стал защитой. Шифрование, подписанный журнал, работа без интернета.
